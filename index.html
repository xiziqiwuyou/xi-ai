Quickstart

快速开始

所有请求都应通过 HTTPS 发送，并在请求头中携带 API Key。下面的示例调用对话补全接口， 返回模型生成的文本结果和用量信息。

cURL 
curl --request POST 'https://api.xi-ai.cn/v1/chat/completions' \
  --header 'Authorization: Bearer $XI_API_KEY' \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "model": "gpt-4o-mini",
    "messages": [
      {
        "role": "user",
        "content": "用一句话介绍 Xi AI API。"
      }
    ],
    "temperature": 0.7,
    "max_tokens": 256
  }'

Authentication

认证方式

在每个 API 请求中加入 Authorization 请求头。API Key 请只在服务端环境、 私有终端或受信任的调试页面中使用。

Header 必填 说明
Authorization 是 Bearer sk-... 格式的访问令牌。
Content-Type POST 请求必填 固定为 application/json。

Models

获取模型列表

GET

查询当前账号可用的模型。模型名称以实际控制台权限为准。

GET /v1/models
请求示例 
curl --request GET 'https://api.xi-ai.cn/v1/models' \
  --header 'Authorization: Bearer $XI_API_KEY'

响应示例

{
  "object": "list",
  "data": [
    {
      "id": "gpt-4o-mini",
      "object": "model",
      "owned_by": "xi-ai"
    }
  ]
}

Chat Completions

创建对话补全

POST

对话补全接口接受按角色组织的消息数组，适用于聊天机器人、文本生成、信息抽取和工具调用前的意图理解。

POST /v1/chat/completions
参数 类型 必填 说明
model string 是 要调用的模型 ID，例如 gpt-4o-mini。
messages array 是 消息列表，常用角色为 system、user、assistant。
temperature number 否 采样温度，推荐范围 0 到 2。
max_tokens integer 否 限制生成文本的最大 token 数。
stream boolean 否 是否启用流式响应。浏览器调试台默认关闭。

响应字段

{
  "id": "chatcmpl_xxx",
  "object": "chat.completion",
  "created": 1710000000,
  "model": "gpt-4o-mini",
  "choices": [
    {
      "index": 0,
      "message": {
        "role": "assistant",
        "content": "Xi AI API 提供统一的模型调用入口。"
      },
      "finish_reason": "stop"
    }
  ],
  "usage": {
    "prompt_tokens": 18,
    "completion_tokens": 16,
    "total_tokens": 34
  }
}

Embeddings

创建文本向量

POST

将文本转换为向量，可用于语义检索、聚类、推荐排序和 RAG 知识库召回。

POST /v1/embeddings
参数 类型 必填 说明
model string 是 向量模型 ID，例如 text-embedding-3-large。
input string | array 是 要转换为向量的文本或文本数组。 
curl --request POST 'https://api.xi-ai.cn/v1/embeddings' \
  --header 'Authorization: Bearer $XI_API_KEY' \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "model": "text-embedding-3-large",
    "input": "Xi AI API 支持统一模型调用。"
  }'

Images

创建图像生成任务

POST

根据自然语言提示词生成图像。不同模型支持的尺寸、质量、返回格式可能不同，请以接口实际返回为准。

POST /v1/images/generations
curl --request POST 'https://api.xi-ai.cn/v1/images/generations' \
  --header 'Authorization: Bearer $XI_API_KEY' \
  --header 'Content-Type: application/json' \
  --data-raw '{
    "model": "gpt-image-1",
    "prompt": "一张干净的 API 控制台产品截图风格插画",
    "size": "1024x1024",
    "n": 1
  }'

Errors

错误码

HTTP 状态 常见原因 处理建议
400 请求体格式错误、参数缺失或模型不支持该参数。 检查 JSON、参数类型和模型 ID。
401 API Key 缺失、错误或已失效。 重新生成 Key，并确认 Bearer 前缀。
403 账号无权访问该模型或资源。 确认模型权限、套餐和组织配置。
429 请求频率过高或额度不足。 降低并发，查看限流响应头和账户余额。
500 服务端或上游模型服务异常。 记录请求 ID，稍后重试或联系支持。

Debugging

返回调试

在线测试面板会展示状态码、耗时、响应头和格式化后的响应体。若浏览器提示跨域错误， 说明接口未允许当前页面源直接访问，可复制生成的 cURL 在终端执行，或在自己的服务端增加调试代理。

Latency 定位网络耗时、上游排队和超时问题。
Headers 查看请求 ID、限流、缓存和内容类型。
Error Body 读取 error.message、error.type 和错误码。
